# [爱是“看见”，而不只是“被看见”](https://hoo.be/yingshic)


我们都渴望在爱里被看见——被关注、被欣赏、被铭记。但更深层次的爱，源于一种主动的“看见”。

“看见”是，你不仅能察觉她新换了口红的色号，更能读懂她笑容背后藏着一丝疲惫；“看见”是，你不仅为他的成功喝彩，更能理解他强大外表下偶尔的脆弱与不安。

这是一种全然的接纳。我不只爱你光彩照人的样子，更心疼你卸下铠甲后的伤痕，理解你所有奇怪的小癖好背后的由来。当我“看见”了真实的、不完美的你，并依然选择深爱，这才是爱最深厚的根基。

所以，请将目光从自己的得失上移开，真正地、耐心地去凝视你身边的那个人。去看见他的灵魂，听见她未说出口的话。当两个人都努力去“看见”对方时，便不会再有“无人懂我”的孤独。
